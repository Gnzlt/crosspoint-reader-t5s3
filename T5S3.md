# CrossPoint on the LilyGO T5 E-Paper S3 Pro

This fork builds upstream [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader) for the
**LilyGO T5 E-Paper S3 Pro** (H752-01). It keeps as close to upstream as possible.

- **The device:** ESP32-S3 with 16 MB flash and 8 MB PSRAM, and a 4.7" ED047TC1 e-paper panel (960×540).
- **Already in upstream:** the FreeInk SDK has a LilyGo profile (`FREEINK_DEVICE_LILYGO`), but CrossPoint has no
  build env for it and doesn't run it in CI.
- **What this fork adds:** that build env and the few fixes the board needs.

Branches:
- `t5s3` is the port (default branch).
- `develop` mirrors upstream.

## What's changed from upstream

| Where | Change | Why |
|---|---|---|
| `platformio.ini` | New `[env:lilygo_t5s3]` | Uses M5GFX 0.2.33, octal PSRAM (`qio_opi`) and QIO flash. The env in upstream's `docs/contributing/touch-and-ui.md` doesn't build: M5GFX 0.2.20 is no longer on the registry, and the env is missing PSRAM |
| `lib/hal/HalGPIO.cpp` | Calls `BoardT5S3::disableGpsLora()` before the SD card mounts | Releases the SX1262's chip select, which shares the SPI bus with the SD card, and turns off the GPS/LoRa power rail. Upstream never called it |
| `freeink-sdk` → [Gnzlt/freeink-sdk@t5s3](https://github.com/Gnzlt/freeink-sdk/tree/t5s3) | LilyGo profile: no power latch on GPIO2 | GPIO2 is the RTC interrupt on this board, not a power switch |
| same | VCOM −1600 → −1560 mV | The panel's factory value |
| same | `headerOffsetY` 0 → 12 | The stock shell hid the header battery at the top edge |

## Build and flash (macOS)

```bash
git clone --recursive https://github.com/Gnzlt/crosspoint-reader-t5s3.git
cd crosspoint-reader-t5s3
~/.pyenv/versions/3.12.13/bin/python3.12 -m venv .venv
.venv/bin/pip install 'https://github.com/pioarduino/platformio-core/archive/refs/tags/v6.1.19.zip'
.venv/bin/pio run -e lilygo_t5s3                                         # build
.venv/bin/pio run -e lilygo_t5s3 -t upload --upload-port /dev/cu.usbmodem*  # flash
.venv/bin/pio device monitor -b 115200                                   # serial log
```

The image is `.pio/build/lilygo_t5s3/firmware.bin`, which flashes at 0x10000. Upload also writes the bootloader
and the partition table.

To bring in newer upstream changes:

```bash
git fetch upstream
git rebase upstream/develop
git submodule update
```

## Controls

- **Touch:** tap and swipe as on upstream's touch devices.
- **Home key:** the round touch key beside the screen goes to Home.
- **BOOT button:** the power button. A short press sleeps the device and a press wakes it.
- **IO12 button:** the side key behind the I/O expander; it acts as Down / next page.

## Known gaps (upstream behaviour, not fixed here)

- Grayscale is 4 levels, not 16.
- Before deep sleep, the front light and the touch controller are left on.
- Touch doesn't wake the device from sleep; use BOOT.
- On LilyGo, the I2C bus has no shared lock across tasks.
- OTA updates look for an official `-lilygo` release asset, which upstream doesn't publish. Update over USB instead.
